# Generate SQL Code with AI in a File Space

Use the *Generate SQL* command and prompt SAP Datasphere to generate code for your SQL views. You can create a view from scratch or modify existing SQL code.

1.  Click <span class="SAP-icons-V5"></span> \(Generate\) ** \> *Generate SQL* \(or press [CTRL\] + [G\]  on Windows, or [CMD\] + [G\]  on iOS\) to open the prompt panel.
2.  Drag the sources that you want SAP Datasphere to use from the *Source Browser*, and drop them in the prompt panel. The *Select Source Delta Settings* dialog opens.
3.  The *Select Source Delta Settings* allows you to decide what data will be used code generation. Either select *All Active Records* or *Delta Capture*.
4.  \[optional\] Select SQL code for the AI to focus on.
5.  Enter your prompt describing the output that you want from your SQL view and then click *Send Prompt* \(or press [Enter\]\).

    SAP Datasphere will generate SQL code in response to your prompt.

6.  Review the generated code. You can:

    -   Enter a new prompt to make further modifications.
    -   Manually modify the code.
    -   Click *Reject* to reject and roll back the proposed changes.

    You can work iteratively with prompts and manual editing as necessary until you are satisfied with the code.
