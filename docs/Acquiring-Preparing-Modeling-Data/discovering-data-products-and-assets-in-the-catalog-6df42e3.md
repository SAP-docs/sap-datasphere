# Discovering Data Products and Assets in the Catalog

Users with a catalog user role can browse for trusted data and analytic assets that have been published to the catalog.



<a name="loio6df42e3675324d73bd35c2e70d46a7ee__section_csj_42x_jdc"/>

## Discover Data Products and Assets

In the catalog, you can find data products and assets:

-   Data products are high-quality, coherent datasets accessible through APIs. Use them in various SAP or third-party products across different data regions to make better business decisions. Data products are available in the following collections:
    -   The *Data Products* collection contains data products from various SAP applications, such as SAP Customer Data Platform, or from supported external partners, such as SAP Databricks.
    -   The *Data Products \(Marketplace\)*collection is only available in SAP Datasphere because it contains data products created in an SAP Datasphere system.

-   The *Assets* collection contains data objects from connected SAP systems. For example, a local table or view sourced from SAP Datasphere, or a story from SAP Analytics Cloud.

From the catalog search page, you can search for data products and assets by selecting the collection that you want and then selecting one or more filters to narrow the search results. See [Searching for Data Products and Assets in the Catalog](searching-for-data-products-and-assets-in-the-catalog-1047825.md).



<a name="loio6df42e3675324d73bd35c2e70d46a7ee__section_jgc_p2x_jdc"/>

## Evaluate Data Products and Assets

To determine whether a data product or asset meets your needs, use the information on its details page to help you decide. The object's details page contains metadata extracted from the source system.

-   For data products, you can review summary properties \(such as name and data provider\), a list of objects within the data product, terms of use, sample data \(if available\), links to documentation or resources on how to use it, and more.
-   For assets, you can review the name and description and related objects. You can also review any catalog enrichments, such as links to glossary terms, KPIs, and tags.
-   For both data products and assets, you can view the impact and lineage analysis diagram. This diagram shows the object's source, the transformations it goes through, its final state, and other objects affected by changes made to it.

For more information about the details page, see [Data Product Details](data-product-details-71f4d15.md), [Marketplace Data Product Details](marketplace-data-product-details-f59e912.md), and [Catalog Asset Details](catalog-asset-details-afccc58.md).

## Access Data Products and Assets

When you find the data product or asset you want, you can do one of the following:

-   Install the data product where you need it \(see [Installing Data Products](installing-data-products-ea7cb80.md) and[Installing Marketplace Data Products](installing-marketplace-data-products-92c35ef.md)\).

-   Open the asset in its source system where you can view it or work with it as part of an existing data project to build something new \(see [Accessing Catalog Assets](accessing-catalog-assets-dc061a2.md)\).
