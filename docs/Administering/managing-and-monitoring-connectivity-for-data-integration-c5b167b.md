# Managing and Monitoring Connectivity for Data Integration

Users with an administrator role can monitor and troubleshoot Data Provisioning Agent and Cloud Connector connectivity.

SAP Datasphere displays system issues impacting your objects. In addition, you can subscribe to the **SAP Cloud Availability Center \(CAC\)** notifications to receive notifications for impactful updates. You can subscribe in two places:

-   The SAP Support Portal
    1.  Go to the [SAP Support Portal](https://support.sap.com/en/my-support/systems-installations/cac.html?isu_page=1&anchorId=section).
    2.  Navigate to the Cloud Availability Center section.
    3.  Subscribe to the relevant systems and components.

-   SAP for Me
    1.  Follow the instructions from the blog [New Cloud Outage Notification Subscription User Experience in SAP For Me!](https://community.sap.com/t5/blog-posts-about-sap-websites/new-cloud-outage-notification-subscription-user-experience-in-sap-for-me/bc-p/14331739/emcs_t/S2h8ZW1haWx8dG9waWNfc3Vic2NyaXB0aW9ufE1MVENVQUJJNE5CSE9CfDE0MzMxNzM5fFNVQlNDUklQVElPTlN8aEs).
    2.  Access the new Cloud Outage Notification subscription interface in SAP for Me.
    3.  Configure your notification preferences.
